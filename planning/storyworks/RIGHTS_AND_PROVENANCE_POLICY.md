# Rights and Provenance Policy

## Rule

No asset enters a pilot edit without traceable commercial-use authority or an original creation record. “Online,” “Creative Commons,” “public domain” and “AI-generated” are starting claims to verify, not automatic clearance.

## Required asset ledger fields

| Field | Requirement |
|---|---|
| Asset ID | Stable pilot-prefixed identifier |
| Description | What the asset contains and intended use |
| Source / creation record | Direct URL or generation/commission record |
| Creator / rights holder | Identified party; unknown is not approved |
| Licence | Exact licence/version or written grant |
| Permitted use | Commercial video, derivative, territory/platform limits |
| Attribution | Exact required wording |
| Acquisition date | Download/generation/commission date |
| Project/video | Pilot and scene |
| Modifications | Crop, colour, animation, compositing, translation, etc. |
| Evidence location | Saved licence page, receipt, release or screenshot |
| Expiry/restriction | Term, revocation, exclusivity, model/person/property limits |
| Approval status | Proposed / verified / rejected / replace |

## Preferred order

1. Original diagrams, maps, typography and recordings.
2. Commissioned work with written commercial rights and source-file terms.
3. Verified public-domain assets with provenance.
4. Compatible commercial licences with retained evidence.
5. Fair-use/fair-dealing reliance only after specific legal-risk review.

Never use downloaded YouTube clips, unlicensed music, copied scripts or assets with unknown creators.

## AI provenance

Record tool/model, prompt or brief, generation date, account/plan, applicable commercial terms, source inputs, human modifications and whether a realistic altered-content disclosure is recommended. Do not imitate a living artist or clone another person’s voice.

## Storage

Git stores text, manifests, checksums and small reference images only. Large media remains in an owner-approved external store. No new paid store is authorised.

## Final rights gate

A pilot fails QA if any included asset is `unknown`, `proposed` or missing retained evidence. A licence check is repeated immediately before publication because terms and restrictions can change.
