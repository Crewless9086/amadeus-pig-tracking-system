# Petra Edit Plan

## Format

- 16:9, 1080p minimum planning target.
- 13–15 minutes.
- Diagram-led documentary; no rapid generic montage.
- Visual change or purposeful movement roughly every 5–10 seconds without forcing constant cuts.

## Structure

| Section | Purpose | Visual rhythm |
|---|---|---|
| Opening | Establish scarcity/flood paradox | Atmospheric stills plus accelerating map flow |
| Read landscape | Teach watershed logic | Slow maps and gravity paths |
| Slow surge | Explain distributed intervention | Cross-section and conceptual hydrograph |
| Divert | Show Siq risk and route choice | Plan view and maintenance details |
| Supply/quality | Connect storage, spring flow and settling | Clean explanatory animation |
| Urban life/display | Reveal consequence and power | Wider visual breath; garden/pool schematic |
| Knowledge/maintenance | Replace “magic” with adaptation and labour | Network and repeated maintenance loop |
| Conclusion | Reassemble system and thesis | Five layers resolve into one map |

## Editorial controls

- Every reconstruction visibly labelled `SIMPLIFIED RECONSTRUCTION` on first appearance.
- No stock footage from unrelated deserts or floods presented as Petra.
- No dramatic flood sound under claims that imply documented ancient events.
- Source notes appear in description and optional end card, not as unreadable constant citations.
- Flag any script shortening that removes an uncertainty qualifier for fact-check review.

## Current status

Planning only. No editor, software purchase, external media or final export exists.
