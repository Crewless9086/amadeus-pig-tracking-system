# Agent Asset Compatibility Pointer

Lifecycle: `POINTER_ONLY / NON_DOCTRINE`.

Agent identity and role authority is `../09-vault-brain/02-agents/AGENT_REGISTRY.md`.
Runtime asset metadata is `../../static/assets/agents/agent_registry.json` and
the corresponding per-agent `agent.json`; browser paths use `/assets/agents/`.

Asset files remain under `static/assets/agents/<agent-id>/`. Use versioned,
lowercase names and update the runtime JSON instead of overwriting an approved
version. UI missions must load the mandatory Facelift and UI standards. This
path is not an approval register and does not prove an image or voice is live.
