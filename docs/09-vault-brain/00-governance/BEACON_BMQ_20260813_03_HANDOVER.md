## Outcome

The completed eight-photo Bella album is the genuine evidence source for one
owner-friendly private review journey. Deployed Oom Sakkie/BEACON presents a
bound Telegram decision card with a direct link to the authenticated Farm App,
which renders the ordered private contact sheet from the same album digest, and

The development terminal may deploy and observe, but may not press a button or
create an owner decision.

## Implemented candidate

- The Farm App loads one exact completed-album packet with retained context,
  ordered thumbnails and simple Library Accept/Reject and Public Use
  Approve/Decline controls.
- Telegram semantic requests use the authenticated shared gateway and one
  protected callback claim. Buttons expose no command, token, digest or storage
  identity. Approve and Decline have the same crash-safe replay behavior.
- Group decisions append to the existing media-library event rail. Each event
  carries the exact album, contract version, snapshot digest, ordered position,
  binary/content hash, decision type, predecessor and owner action identity.
- Public Use is unavailable until every original has server readback hash
  proof, a private thumbnail and a named, versioned affirmative review for
  privacy, people/identifiers, location disclosure, animal welfare, brand,
  health/sales claims and Meta organic-awareness suitability. That exact
  understanding-event identity is part of the album digest. Approval is scoped
  only to later organic farm-awareness review.
- Reject/Decline buttons state the selected reason. Browser review also accepts
  a short owner-written reason. Later reconsideration appends a successor;
  it never changes history.

## Authority boundary

Library acceptance does not approve Public Use. Public Use does not approve a
campaign or publication. Campaign Review and Publication remain later locked
actions. This mission performs no public post, schedule, customer contact,
spend, farm write, hardware command, n8n mutation or Google Sheets mutation.
