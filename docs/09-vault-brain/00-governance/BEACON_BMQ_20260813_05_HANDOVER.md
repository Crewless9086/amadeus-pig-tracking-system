# BEACON BMQ-20260813-05 protected publication foundation

Mission lifecycle state: WORKING — target stop is `OWNER_HOLD / LOCAL_PROTECTED_PREVIEW_READY`.

This source-only candidate composes the existing BEACON proposal, public-use,
organic publication and performance concepts into one exact protected review
packet. The packet's digest is local preview identity; its `rail_translation`
maps exact caption/media values onto the already-canonical decision/binding
inputs and creates no new ledger. It performs no deployment, Meta call, Telegram delivery, publication,
schedule, spend, customer send, farm write, n8n or Sheets mutation.

The packet binds proposal/digest, objective, organic channel, exact copy version,
ordered media hashes and public-use event identities, owner/chat/card, verified Meta page,
and immediate or exact zoned scheduled timing. Reach,
engagement, qualified SAM leads, conversions, completed sales and attributable
gross profit begin as `Unknown`. SAM retains independent enquiry and sales truth.

Owner choices are `Approve / Correct / Decline`. The preview defines their exact
semantics but deliberately performs none of them. Approval, correction, decline,
one-attempt execution, provider rejection/ambiguity, receipts and replay remain
owned by the existing weekly-decision, organic-binding, authorization, Facebook
execution and performance rails. No competing table or coordinator is added.
Organic authority never grants paid spend.
