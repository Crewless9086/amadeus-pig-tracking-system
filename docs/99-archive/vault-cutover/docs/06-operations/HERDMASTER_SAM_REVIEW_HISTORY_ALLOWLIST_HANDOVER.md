## Source contract

`litter_supersession_service` now classifies each immutable SAM review row by:

- `review_event_id`;
- exact referenced superseded child identities;
- exact governed JSON paths for those identity scalars;
- canonical `decision_json` SHA-256;
- classification `immutable_historical_review_snapshot`.

The manifest count, IDs and aggregate hash participate in deterministic
 operation identity and replay validation. Enabled trigger type, bound function,
 trigger-definition hash, exact blocking function body hash and function
 security/configuration properties are also bound. The service still rejects every
actionable owner-review field, unsupported source/path and all other downstream
references.

The additive migration:

- adds exact historical-reference manifest fields to `litter_supersessions`;
- replaces the service-only procedure with a signature that binds the manifest;
- adds `current_actionable_sam_live_stock_review_events`;
- leaves `sam_live_stock_conversation_review_events` byte-for-byte unchanged;
- retains database rejection of any new reference to a disposed identity.
