# HERDMASTER Breeding Attention UI Recovery Plan

Status: owner-approved and queued after the current HERDMASTER weaning-led eligibility correction.

## Owner-visible outcome

The Breeding Attention page must answer two different questions without duplication:

1. **Dark-green work cards — What must we do?**
2. **Animal evidence table — What do we know about each animal?**

## Dark-green work cards

Show only actionable or genuinely held animals. Each card must use natural Afrikaans and contain:

- sow name;
- concise current position;
- actual reason;
- primary and reserve boar when applicable;
- proposed placement and 17-day exposure timing;
- one exact next action.

Do not expose generic internal phrases such as `owner review`, `evidence gap`, `availability` or `current heat observation`.

## Animal evidence table

Retain all current breeding animals and show:

- latest individual observation and timestamp;
- factual note and physical/temperament facts;
- current lifecycle;
- latest litter and governed weaning chronology;
- primary/reserve boar when available;
- real hold or required fact;
- next management action.

Replace `Ontbrekend / teenstrydig` with `Werklike houvas / Benodigde feit`. Do not list every internal Unknown. Prefer explicit farm wording such as `Geen huidige houvas`, `Aktiewe werpsel`, `Waarskynlik dragtig`, `Liggaamskondisie-kommer`, `Teenstrydige voortplantingsrekord` or `Eienaarhouvas`.

## Required reconciliation

- Remove standing-heat evidence from the page's missing-fact presentation.
- Apply the approved foundation-herd ancestry rule instead of repeating family-tree Unknown for every animal.
- Show withdrawal only when an attributable current withdrawal concern exists.
- Treat current body-condition evidence as satisfied when recorded; a real concern affects only that animal.
- Close historical pregnancy interpretation when later attributable litter and weaning evidence proves that lifecycle progressed.
- Prevent the action cards and evidence table from repeating the same generic paragraph.
- Keep all visible owner wording in natural Afrikaans.

## Completion proof

Use current evidence for Ms Piggy, Lolly, Lucy, Olive, Shupe and Sophie. The owner must be able to distinguish the six animals immediately, see which are actionable or genuinely held, understand why, and identify the next mating-management action without interpreting system vocabulary. Local owner approval is required before deployment.
